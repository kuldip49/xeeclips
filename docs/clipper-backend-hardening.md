2. **Schema status.** Audited all seven campaign models. Campaign ownership/project FKs use Restrict; campaign children and posts cascade within their workflow; source videos are Restrict; deleted generated/editor references become nullable via SetNull. Unique project, brief, storage key, campaign/source, run request/source, campaign/generated clip and one-post-per-clip constraints remain. Missing canonical projects now yield UNKNOWN. Existing String state columns gain database CHECK guards rather than type conversions. Earnings remain `DECIMAL(14,2)` and are aggregated by currency.

3. **Migration SQL/status.** Existing `20261017000000_clipper_workspace_v1` was reviewed and left unchanged. New [additive SQL](../apps/backend/prisma/migrations/20261018000000_clipper_backend_hardening/migration.sql) adds 17 state/value checks and five FK lookup indexes. No drops, column conversions, deletes or data rewrites. SQL was shown before execution. Built a disposable pre-Clipper PostgreSQL database using the 35 pre-feature migrations, seeded existing user/project/video/job/generated clip/editor records, dumped and restored it into a second database, then applied the two campaign migrations. All six legacy records retained their SHA-256 fingerprint; all 17 checks and 13 campaign FKs were verified; invalid state/count inserts failed. This was a production-shaped synthetic legacy copy, not a production backup. Production was never queried or migrated for this exercise. ADD CONSTRAINT/CREATE INDEX still take normal PostgreSQL locks; no production rollout is authorized here.

4. **Ownership/security.** Explicit HTTP integration denies User B access to User A across 21 campaign, brief, asset, source, clip, compliance, fix, export, Ready, Posted, performance and metric endpoints. Ordinary admin access stays tenant scoped. Foreign video/source/asset/editor references fail. Existing auth suite additionally passed reciprocal project/media/editor/Quick Reframe/History ownership, private storage, session, consent, CSRF and account controls. No ownership bypass was added.

5. **Asset security.** Extension, MIME, magic bytes, actual disk size, ffprobe decodability, dimensions/duration, media type/use, owner/campaign binding and safe relative paths are checked. Header probing reads 64 bytes rather than loading large media into Node memory. TXT is bounded UTF-8, extracted once; PDF/DOCX are reference-only. Display names remove traversal components, controls and bidi overrides, preserve the verified extension and remain bounded. Storage uses scoped UUID keys. Asset changes and confirmation invalidation are transactional; failed uploads clean storage; failed post-deletion storage cleanup cannot roll back the database mutation. DTOs omit keys and extracted text. Invalid ranges return safe 416 responses and `Content-Range`.

6. **Free parsing.** Original deterministic duration/topic/keyword/CTA/logo/music/captions/hashtags/platform/posting/content/deadline/payout cases still pass. Added explicit media negation, multiline tags/mentions, partial natural-language uncertainty and conflict recomputation. Unknown/ambiguous content remains NEEDS_CONFIRMATION/UNKNOWN. Optional and excluded media no longer invent positive requirements. No online interpreter is used for Free.

7. **Pro parsing.** Existing router, consent and online policy are retained. Grounded audience/tone proposals, structured output, contradictory topics and ambiguous wording were tested with mocks over HTTP. Normalization recomputes conflicts after proposals and manual updates; malformed relevance IDs/scores are rejected. Busy understanding returns the exact public `XEEPRO_BUSY` response without modifying source text, brief version/data/confirmation or credit balance. Every provider call was mocked; no real quota was spent.

8. **Campaign ranking.** Required-topic A survives ahead of unrelated B, while forbidden-topic C is rejected, even when B/C have higher generic and mocked semantic scores. Confirmed duration, forbidden content and required-keyword gates retain priority. Ranking uses cached candidate evidence and the existing engine's usable complete boundaries; no replacement clip engine was introduced.

9. **Free zero-cloud proof.** Ran complete HTTP source upload → local ASR/analysis → campaign understanding/assets → generation/ranking → compliance → canonical project/style/branding → actual export/download for Free StyleOne and StyleTwo. Both exported portrait audio/video verified by ffprobe. Router and provider transports were trapped, with an additional external-fetch guard. Seven Free telemetry contexts recorded `openAiCalls=0`, `cloudLlmCalls=0`, `proEscalations=0`, `blockedProviderAttempts=0`; `freeAttempts=0`, `transportAttempts=0`. The saved media audit covers the full flows, not just parser return values.

10. **Compliance.** All five individual states are preserved; overall FAIL/UNKNOWN cannot become Ready. Added checks for blank subtitles, media outside the retained timeline, optional/excluded media, literal required keywords, forbidden social copy, spoofed mention suffixes, punctuation-only CTA and CTA masquerading as a headline. Semantic, audience/tone, reference and posting details retain human WARN/UNKNOWN review. Missing speech evidence is UNKNOWN rather than a claimed content PASS.

11. **Compliance after edits.** Real canonical commands removed a required logo (FAIL), explicitly fixed it (PASS), trimmed below the allowed duration (FAIL), restored through Undo (PASS), reapplied through Redo (FAIL), and changed CTA (FAIL). Recomputed against current editor/brief versions without regenerating video or reserving generation credits. Revision/brief changes invalidate Ready. Compare-and-set prevents stale social/compliance writes from overwriting current state; bounded retries handle changed inputs. A forced compliance refresh racing Mark Posted preserved POSTED.

12. **Canonical editor integration.** Campaign clips still reference existing GeneratedClip/EditProject records, media elements, persisted history and the existing renderer. Real StyleOne/StyleTwo/StyleZero paths exercised headlines/captions, existing style zoom/layout behavior, campaign logo/music/CTA and exports. Undo/Redo persistence is verified through existing routes. Preview/download/export revisions agree. No duplicate editor model or renderer change was made.

13. **Credits/concurrency.** Each successful Free StyleOne, Free StyleTwo and mocked Pro StyleZero generation consumed exactly one existing-policy credit. Repeated request admission returned the same run; eight concurrent requests created one run; conflicting reuse of a key returns 409. Per-source PostgreSQL advisory locks prevent two scanners from dispatching the same source generation. Busy before admission made no ledger entry. Busy after reservation produced one reserve and one refund (`1|1`), with unchanged balance after repeated scans and no campaign output/Free fallback. Local compliance/fix/edit/post/metric operations preserved balance. The auth suite separately exercised one credit/two concurrent jobs, double-refund prevention and atomic settlement.

14. **Posted/performance.** Ready/Posted require current confirmed brief, checked canonical revision, valid compliance and the current export. Concurrent social change cannot be overwritten by stale Ready acceptance. Recorded post and lifecycle transition commit together. HTTPS URLs reject credentials. Negative/fractional/out-of-bound counters, over-precision earnings and invalid currency are rejected. No synthetic popularity/earnings are returned as product data.
